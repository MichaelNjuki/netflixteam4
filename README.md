# Netflix Team 4 Project

## Overview
This project focuses on Netflix movie data analysis using Python and Jupyter Notebook.

## Project Files
- `Movie.ipynb` – Movie data analysis.
- `moviepipeline.ipynb` – Data processing pipeline.
- `Netflix (1).ipynb` – Netflix dataset analysis.
- `Operations.ipynb` – Project operations.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run
1. Clone or download the project.
2. Open the folder in VS Code.
3. Install the required libraries.
4. Open and run the notebooks.
